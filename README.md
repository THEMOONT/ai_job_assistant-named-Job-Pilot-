# 🚀 JobPilot

AI-powered job search automation platform that helps users find better opportunities faster.

JobPilot analyzes resumes, matches users with relevant jobs, enables bulk apply workflows, tracks applications, and gives a premium dashboard experience.

---

# 🌟 Features

## 🔐 Authentication
- User Signup
- User Login
- Session Storage
- Personalized Dashboard

## 📄 Resume Intelligence
- Upload Resume (PDF / DOCX)
- Resume Parsing
- Skill Extraction
- Candidate Profile Creation

## 🤖 AI Job Matching
- Smart Job Recommendations
- Match Score Engine
- Location Based Filtering
- Skill Based Ranking

## 💾 Job Management
- Save Jobs
- Applied Jobs Tracker
- Bulk Apply System
- Application Status Monitor

## 📊 Dashboard Analytics
- Recommended Jobs Count
- Saved Jobs Count
- Applied Jobs Count
- Career Progress Insights
